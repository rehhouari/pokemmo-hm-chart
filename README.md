# PokeMMO HM Chart

HM chart and Pokémon compatibility for PokeMMO


Inspired by [pokemondb's HMs Chart](https://pokemondb.net/firered-leafgreen/hms)			


## Development

- uses alpine.js for logic.
- uses [pico.css](https://picocss.com/) for quick styling.


```sh
bun i
bun run dev
```

copy "monsters.json" from PokeMMO dump into `data` if you want to use
 `filter-hms.ts`.
